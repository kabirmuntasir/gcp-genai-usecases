# GCP Generative AI Use Cases

This repository contains a collection of projects showcasing various applications and implementations using Google Cloud Platform's Generative AI services. Each project demonstrates different use cases and implementations of GenAI technology.

## Projects

### 1. GenAI Customer Care
Located in `/genai-customercare`

A customer service chatbot application that leverages Google's Generative AI to provide intelligent responses to customer queries. Built with Streamlit for a user-friendly interface and deployed on Google Cloud Run.

### 2. Streamlit Chatbot
Located in `/streamlit-chatbot`

A general-purpose chatbot implementation using Streamlit and AI capabilities, demonstrating basic chatbot functionality with a clean web interface.

## Repository Structure

```
gcp-genai-usecases/
├── genai-customercare/    # Customer service AI chatbot implementation
├── streamlit-chatbot/     # Basic Streamlit chatbot example
└── README.md             # Repository documentation
```

## Getting Started

Each project contains its own README with specific setup instructions and documentation. Navigate to the respective project directories to get started with individual implementations.

## Prerequisites

- Python 3.8+
- Google Cloud Platform account
- Required API access and credentials for GCP services
- Docker (for containerized deployments)
